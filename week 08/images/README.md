Images folder

- Sample SVG images included: `project1.svg`, `project2.svg`, `project3.svg`, `profile.svg`.
- To replace with real images, add files named `project1.jpg` (or .png/.svg), `project2.jpg`, `project3.jpg`, and `profile.jpg`.
- Recommended sizes:
  - Project thumbnails: 1200x800 (will be scaled down)
  - Profile: square 400x400
- If you don't add local images, the pages use the provided local SVGs or remote placeholders.
- To add images, place them in the `images/` folder next to the HTML files.
